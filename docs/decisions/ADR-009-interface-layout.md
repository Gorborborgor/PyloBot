# ADR-009: Розміщення інтерфейсів — панель зверху попереду

> **Статус:** прийнято
> **Дата:** 2026-10-21
> **Автор рішення:** Данило Степанов
> **Пов'язані документи:** `docs/trz.md` (IR-1…IR-6), `docs/decisions/ADR-001-mcu.md`, `docs/decisions/ADR-005-chassis.md`

## 1. Контекст

Потрібно визначити, які елементи керування й індикації має робот і де вони розташовані.

## 2. Рішення

Зверху попереду розміщуються:

- тумблер живлення;
- кнопка запуску прибирання;
- маленький простий екранчик;
- маленький простий динамік;
- один різнокольоровий світлодіод;
- USB-C для прошивки MCU.

Роз'єм заряджання батареї (XT60 і DC-штекер) розташовується окремо, місце визначається під час моделювання корпусу.

## 3. Наслідки

- Лідар стоїть по центру зверху (ADR-005), тому всі елементи панелі мають бути нижче площини його сканування, щоб не закривати передній сектор.
- Тумблер стоїть у силовому колі, тож його номінал має відповідати струму батареї на постійному струмі. Чи виконує він функцію аварійного знеструмлення (FR-17), вирішується в схемі живлення.
- Екранчик виходить за межі IR-1…IR-6 із ТЗ; ТЗ треба доповнити. Анімація лишається в списку майбутнього.
- Зовнішній USB-C для прошивки обмежує канал Pi ↔ MCU: у Blackpill один USB-порт (питання відкрите, вирішується разом з платформою прошивки).
- Біля роз'єму заряджання залишається місце для майбутніх контактів док-станції.
