# ADR-008: Датчики — механічний бампер, ІЧ-промінь у контейнері, castor-датчик підняття

> **Статус:** прийнято
> **Дата:** 2026-10-21
> **Автор рішення:** Данило Степанов
> **Пов'язані документи:** `docs/trz.md` (FR-2, FR-3, FR-11), `docs/decisions/ADR-001-mcu.md`, `docs/decisions/ADR-002-navigation-algorithm.md`, `docs/decisions/ADR-005-chassis.md`, `docs/decisions/ADR-007-suction-system.md`

## 1. Контекст

Після вибору 2D-лідара (ADR-002) потрібно визначити, які ще датчики потрібні: безконтактний сенсор перешкод, бампер, датчик заповненості контейнера й датчик підняття робота.

## 2. Розглянуті варіанти

| Питання | Варіант | Висновок |
|---|---|---|
| Безконтактний сенсор | Додатковий ІЧ/ToF/ультразвук | Відхилено: лідар покриває перешкоди, а точковий сенсор бачить лише вузьку смугу |
| Бампер | Ємнісний датчик дотику | Відхилено: не реагує на сухі пластикові й дерев'яні перешкоди, чутливий до пилу |
| Бампер | **Механічний, мікроперемикачі** | **Обрано** |
| Заповненість контейнера | Ваговий датчик | Відхилено: шерсть легка, об'єм заповнюється раніше, ніж зростає вага |
| Заповненість контейнера | **ІЧ-промінь на рівні «повно»** | **Обрано** |
| Підняття | Перемикач на колесі | Відхилено: колеса без підвіски |
| Підняття | IMU | Відкладено: IMU не в MVP |
| Підняття | **Рухомий castor з мікроперемикачем** | **Обрано (принцип)** |

## 3. Рішення

- Окремого безконтактного сенсора в MVP немає. Перешкоди бачить лідар, а те, що він пропускає (низькі предмети, сліпа зона, скло), ловить бампер.
- Бампер: рухома дуга по передній половині корпусу на пружинах і 2–3 мікроперемикачі (ліворуч, по центру, праворуч), підключені за схемою NC.
- Заповненість контейнера: ІЧ-випромінювач і приймач на протилежних стінках на рівні «повно».
- Підняття: castor на пружинній ковзанці з ходом 3–5 мм і мікроперемикачем; при спрацюванні MCU вимикає щітку й вентилятор.

## 4. Наслідки

- Сигнал бампера іде на переривання MCU, який зупиняє мотори без участі Pi (ADR-001). Схема NC означає, що обрив дроту сприймається як удар.
- Вікна ІЧ-променя в контейнері запилюються, тому розташовуються так, щоб до них діставала рука при чищенні (ADR-007).
- Струм вентилятора можна використати як додатковий індикатор забитого тракту; вирішується на етапі прошивки.
- Castor із ходом злегка відходить від «чистої» схеми без підвіски (ADR-005), але лишається трьома точками опори; конструкція й хід визначаються під час моделювання корпусу.
- FR-2 («безконтактний сенсор ≥ 3 см») виконується лідаром; формулювання ТЗ треба уточнити під лідар.
- Cliff-сенсор лишається у списку майбутнього; TFmini Plus із наявних можна використати для нього пізніше.
